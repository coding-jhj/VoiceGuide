VoiceGuide MVP Status

시각장애 보행 보조 AI 음성 안내 앱

VoiceGuide는 스마트폰 카메라로 앞쪽 장애물을 인식하고, 서버를 기다리지 않고 기기 안에서 바로 음성 안내와 진동 경고를 제공하는 Android MVP입니다.

On-device TFLite YOLO로 휴대폰에서 직접 객체를 탐지합니다.
즉시 안내 SentenceBuilder가 로컬에서 문장을 만들고 TTS로 말합니다.
실시간 기록 FastAPI 서버가 탐지, GPS, 대시보드 데이터를 저장합니다.
오프라인 대응 서버가 없어도 기본 음성 안내와 진동은 동작합니다.

MVP가 하는 일

보행 중 장애물 안내

카메라 화면에서 사람, 차량, 의자 같은 객체를 탐지하고 위치와 위험도를 계산해 짧은 한국어 문장으로 안내합니다.

찾기와 질문 모드

"의자 찾아줘", "지금 뭐가 있어?" 같은 음성 명령을 받아 현재 인식된 객체를 기준으로 답변합니다.

진동 패턴 경고

위험도가 높아질수록 SHORT, DOUBLE, URGENT 패턴으로 구분해 사용자가 위험 정도를 빠르게 느끼도록 설계했습니다.

보호자/관리자 대시보드

서버에 저장된 탐지 이벤트와 GPS 이력을 실시간 대시보드에서 확인할 수 있습니다.

처리 흐름

1 CameraX 입력 Android 카메라 프레임을 받아 분석 대상으로 넘깁니다.
2 TFLite YOLO 탐지 서버가 아니라 휴대폰에서 객체 탐지를 수행합니다.
3 MVP 안정화 중복 제거, 3프레임 vote, IoU tracking, EMA로 흔들림을 줄입니다.
4 안내와 기록 로컬 TTS/진동을 먼저 실행하고, 서버에는 JSON과 GPS를 저장합니다.

현재 구현 상태

  • 완료 Android 온디바이스 탐지 CameraX, TFLite 모델, 중복 제거, vote, MvpPipeline 안정화 흐름이 연결되어 있습니다.
  • 완료 로컬 음성 안내 서버 응답을 기다리지 않고 Android 내부에서 한국어 안내 문장을 생성합니다.
  • 완료 FastAPI 서버와 DB 저장 /detect, /detect_json, /gps, /events, /history 경로가 구현되어 있습니다.
  • 진행 거리와 방향 안내 품질 개선 bbox 면적 기반 거리 추정과 방향 문구를 실제 보행 환경에 맞게 더 다듬는 단계입니다.
  • 다음 실기기 성능 검증 모델별 FPS, 발열, TTS 중복 발화, 서버 업로드 간격을 실제 Android 기기에서 확인해야 합니다.

주요 API

API 역할 현재 상태
POST /detect Android 탐지 결과를 서버에 저장하고 tracker를 갱신합니다. 완료
POST /detect_json 최근 탐지 상태를 저장하는 호환 경로입니다. 완료
POST /gps 사용자 위치와 이동 경로를 대시보드에 반영합니다. 완료
GET /api/policy Android와 서버가 공유하는 탐지 정책을 배포합니다. 완료
GET /events/{session_id} SSE로 대시보드에 실시간 이벤트를 전송합니다. 완료

남은 핵심 과제

  • 중요 실제 보행 환경에서 안내 정확도 검증 거리 추정, 방향 표현, 위험도 기준이 사용자가 이해하기 쉬운지 테스트가 필요합니다.
  • 중요 TTS와 진동 빈도 조절 너무 자주 말하거나 울리지 않도록 쿨다운과 긴급 예외 조건을 실기기에서 조정해야 합니다.
  • 다음 모델 경량화와 성능 튜닝 FP16/INT8 모델, GPU/XNNPACK fallback, 업로드 샘플링으로 FPS와 발열을 개선합니다.
한 줄 요약: 현재 MVP는 "휴대폰에서 바로 보고, 바로 말해주는 보행 보조 앱"까지 구현되어 있고, 다음 단계는 실제 사용자 환경에서 안내 품질과 성능을 안정화하는 것입니다.
