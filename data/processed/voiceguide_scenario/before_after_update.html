VoiceGuide Data Update

수정 전과 수정 후 데이터 반영 비교

README처럼 실제 앱/발표에서 사용할 계획에 맞춰, 다운로드 폴더의 최종 데이터 4개를 프로젝트 데이터 패키지에 반영한 전후 차이를 정리했다.

4개 새 최종 원본 파일 반영
1,025건 동작구 횡단보도 점수표 유지
8m A/B 경로 거리 차이
3개 TTS 이벤트와 진동 패턴

수정 전

이전 자동 생성 산출물 기준

파일 구성
최종 파일명은 있었지만 데이터 구조가 단순했고 일부 legacy 파일과 설명 자료가 따로 움직였다.
경로 비교
A/B 관리번호와 8m 시나리오는 맞췄지만, 거리 세부 컬럼과 선택 이유 컬럼이 부족했다.
횡단보도 등급
preferred 252, recommended 11, basic 762, insufficient 0
B 경로 근거
B 횡단보도의 보행자작동신호기 정보가 빠져 있어 안내문이 보수적으로 생성됐다.
TTS
안전 경로 선택 이유 중심의 단일 안내 문장에 가까웠다.
수정 후

사용자가 준 최종 데이터 기준

파일 구성
다운로드의 final_* 4개를 그대로 넣고, legacy 파일명과 ZIP까지 같은 기준으로 맞췄다.
경로 비교
approx_distance_m, distance_delta_vs_shortest_m, final_selection_reason을 포함한다.
횡단보도 등급
preferred 54, recommended 314, basic 610, insufficient 47
B 경로 근거
보행등, 음향신호기, 보행자작동신호기 근거가 모두 있는 안전 경로로 표시된다.
TTS
경로 선택, 횡단보도 접근, 실시간 탐지의 3개 이벤트와 진동 패턴을 제공한다.

파일별 수정 전후

파일 수정 전 수정 후
final_route_comparison.csv A/B 비교는 있었지만 필드가 단순했다. 시작지, 목적지, 대표 횡단보도, 거리, 점수, 우선순위, 선택 이유까지 포함한다.
final_crosswalk_accessibility.csv 보행지원시설 점수와 기본 근거 중심이었다. 근접 음향신호기/버튼 ID와 거리까지 포함한 최종 점수표가 됐다.
final_scenario_dataset.json 목적지, 추천 횡단보도, demo pair 중심이었다. TTS guidance와 더 풍부한 A/B 경로 객체를 포함한다.
final_tts_guidance.csv 선택 이유 안내 중심이었다. route_selected, crosswalk_approach, realtime_detection 세 이벤트로 분리됐다.
final_crosswalk_accessibility.geojson 이전 CSV 기준 지도 포인트였다. 최신 CSV 1,025건 기준으로 다시 생성했다.
voiceguide_scenario.zip 이전 산출물 묶음이었다. README에서 쓰는 최종 파일 6개와 summary를 담은 공유용 ZIP으로 갱신했다.
