보행자 사고다발지 데이터 전처리 가이드

19_24_pedstrians.csv를 VoiceGuide 대시보드에서 “사고다발구역”처럼 보여주기 위한 정리 방식입니다. 핵심은 좌표/폴리곤을 지도 레이어로 살리고, 사고 심각도를 점수화해서 위험도 색상과 우선순위로 바꾸는 것입니다.

데이터 요약

전체 사고건수 15,797
전체 사상자수 16,921
사망 / 중상 599 / 15,619

원본 CSV는 CP949 계열 인코딩으로 읽어야 한글 컬럼명이 정상 처리됩니다. 브라우저/서버에서 바로 읽을 때는 UTF-8로 변환한 파일을 별도로 두는 편이 안전합니다.

대시보드용 전처리 흐름

1. 인코딩 통일

원본 CSV를 CP949로 읽고, 프로젝트 내부에서는 UTF-8 CSV 또는 JSON/GeoJSON으로 저장합니다.

2. 컬럼 정리

공백이 있는 지점코드는 trim 처리하고, 숫자 컬럼은 정수/실수 타입으로 변환합니다.

3. 지도 좌표 검증

경도, 위도가 비어 있거나 한국 범위를 벗어난 행은 별도 오류 목록으로 분리합니다.

4. 위험도 점수 생성

사고건수만 쓰면 심각도가 묻히므로 사망/중상에 가중치를 둔 risk_score를 만듭니다.

5. 위험 등급 부여

상위 20%는 고위험, 20~60%는 주의, 나머지는 관심 등급으로 나눠 지도 색상과 필터에 사용합니다.

6. 지도 레이어 변환

다발지역폴리곤은 GeoJSON으로 파싱해서 면 레이어, 경도/위도는 중심점 마커로 사용합니다.

추천 위험도 산식

사고다발구역 느낌을 내려면 “많이 발생한 곳”과 “피해가 큰 곳”이 동시에 올라와야 합니다. 아래 산식은 대시보드 초기 버전에서 쓰기 좋은 보수적인 기준입니다. 

risk_score =
  사고건수 * 1
  + 사망자수 * 10
  + 중상자수 * 4
  + 경상자수 * 1
  + 부상신고자수 * 0.5
생성 컬럼 용도 예시
risk_score 위험순 정렬, 상위 사고다발구역 카드, 지도 마커 크기 서울 강북구 미아사거리역 부근: 110.0
risk_level 지도 색상, 필터, 음성 안내 우선순위 고위험 주의 관심
display_name 지도 팝업/목록 제목 미아동, 미아사거리역 4호선 부근
geojson 사고다발구역 폴리곤 표시 원본 다발지역폴리곤 문자열을 JSON 파싱

대시보드 표시 방식

VoiceGuide에 붙일 때 추천 UI

  • 지도에는 폴리곤 반경을 옅은 빨강/주황 면으로 표시하고, 중심점에는 점수 기반 마커를 둡니다.
  • 현재 GPS 기준 100m, 300m, 500m 안의 위험구역을 계산해서 “근처 사고다발구역” 카드로 노출합니다.
  • 음성 안내는 고위험 구역만 우선 적용하고, 반복 알림 방지를 위해 같은 구역은 일정 시간 동안 재알림을 막습니다.
  • 실내 장애물 감지와 섞일 때는 “즉시 장애물”이 1순위, “지역 위험정보”는 2순위로 두면 UX가 안정적입니다.

전처리 스크립트 예시

최종 산출물은 datasets/pedestrian_hotspots.geojson처럼 프로젝트 안에 두고 서버나 앱에서 읽는 구조가 깔끔합니다.

import csv
import json

source = "C:/Users/ghksw/Downloads/19_24_pedstrians.csv"
features = []

with open(source, encoding="cp949", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        accidents = int(row["사고건수"])
        deaths = int(row["사망자수"])
        serious = int(row["중상자수"])
        minor = int(row["경상자수"])
        reported = int(row["부상신고자수"])

        risk_score = (
            accidents
            + deaths * 10
            + serious * 4
            + minor
            + reported * 0.5
        )

        polygon = json.loads(row["다발지역폴리곤"])
        level = "high" if risk_score >= 80 else "medium" if risk_score >= 45 else "low"

        features.append({
            "type": "Feature",
            "geometry": polygon,
            "properties": {
                "hotspot_id": row["사고다발지fid"],
                "place_name": row["지점명"],
                "district": row["시도시군구명"],
                "accidents": accidents,
                "casualties": int(row["사상자수"]),
                "deaths": deaths,
                "serious": serious,
                "risk_score": risk_score,
                "risk_level": level,
                "center": [float(row["경도"]), float(row["위도"])]
            }
        })

geojson = {
    "type": "FeatureCollection",
    "features": features
}

with open("datasets/pedestrian_hotspots.geojson", "w", encoding="utf-8") as f:
    json.dump(geojson, f, ensure_ascii=False)

프로젝트 적용 체크리스트

  • datasets/에 원본 CSV와 전처리 GeoJSON을 함께 보관합니다.
  • 서버 API는 현재 위치를 받아 반경 내 위험구역만 반환하도록 만듭니다.
  • 대시보드는 전체 지도, 위험구역 Top 10, 지역별 사고건수, 위험등급 필터를 기본 구성으로 둡니다.
  • 앱 안내 문구는 “사고다발구역입니다. 주변 보행에 주의하세요.”처럼 짧게 유지합니다.
  • 개인 실시간 사고 예측처럼 보이지 않게, “과거 사고다발 통계 기반”이라는 표현을 문서와 UI에 남깁니다.
