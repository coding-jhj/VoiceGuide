확정 데이터 기반 시나리오

동작구 지하철역에서 복지관까지, 더 안전한 횡단보도를 선택하는 VoiceGuide

이 시나리오는 “최단 경로 안내”가 아니라, 시각장애인이 건너야 하는 횡단보도를 공공데이터로 비교해 더 설명 가능한 경로를 선택하는 기능에 집중한다. 스마트횡단보도 데이터가 확정되지 않은 경우에는 신호등, 음향신호기, 보행자작동신호기, 횡단보도 위치 데이터를 보행지원시설 정보로 묶어 판단한다.

사용자: 서울 동작구 지하철역에서 장애인복지관으로 이동한다. VoiceGuide는 대시보드 지도에 복지관, 이동지원센터, 횡단보도 후보를 표시하고, 출발 전 공공데이터로 더 안전한 횡단보도를 선택해 최적 이동경로를 그린다. 이동 중에는 YOLO가 계단, 차량, 사람, 문, 장애물을 실시간 탐지해 TTS/진동으로 즉시 안내한다.

핵심 문제와 해결

구분 내용 VoiceGuide가 보여줄 가치
상황 시각장애 사용자가 동작구의 지하철역에서 내려 가까운 장애인복지관으로 이동한다. 목적지는 서울 복지시설 공공데이터에서 찾고, 이동 중에는 보행 안전 판단을 보완한다.
문제 지도 앱의 최단 경로는 빠르지만, 중간에 보행지원시설 정보가 부족한 횡단보도를 지나게 된다. 최단 거리만으로는 시각장애인의 실제 보행 안전을 설명하기 어렵다는 점을 보여준다.
해결 VoiceGuide가 후보 횡단보도를 비교해 보행지원시설 정보가 있는 경로를 선택하고, 이동 중에는 YOLO로 실제 전방 장애물을 탐지한다. 공공데이터는 경로 선택 이유가 되고, YOLO는 현재 눈앞의 위험을 즉시 알려주는 역할을 한다.
안내 “최단 경로보다 90m 더 이동하지만, 보행지원시설 정보가 있는 횡단보도로 안내합니다.” 사용자에게 우회 이유를 짧고 명확한 행동 문장으로 전달한다.
검증 대시보드 지도에 복지관/이동지원센터 마커, 횡단보도 후보 A/B, 선택된 최적 이동경로, 선택 이유, 우회 거리, 안내 문장을 표시한다. 심사위원이 “어디로 안내했고, 왜 그 경로를 선택했는지”를 지도와 데이터 근거로 확인할 수 있다.

시나리오 흐름

1
출발지 확인 사용자가 동작구 지하철역에서 앱을 켜고 “복지관으로 가자”고 말한다.
2
목적지 선택 서울 복지시설 데이터에서 동작구 장애인복지관 후보를 찾고, 대시보드 지도에 시설 마커로 표시한다.
3
횡단보도 후보 비교 최단 경로의 횡단보도 A와 우회 경로의 횡단보도 B를 지도에 표시하고 공공데이터로 비교한다.
4
이동 중 YOLO 안내 우회 경로로 이동하는 동안 카메라가 계단, 차량, 사람, 문, 장애물을 탐지해 방향과 거리 중심으로 안내한다.
5
안전 경로 선택 B가 90m 더 멀지만 보행지원시설 정보가 있어 최적 이동경로로 선택하고 지도에 경로 라인을 그린다.

대시보드 지도에 표시되는 요소

지도 요소 표시 내용 사용 데이터 시나리오 의미
출발지 동작구 지하철역 현재 위치 마커 사용자 GPS 사용자가 어디에서 이동을 시작했는지 보여준다.
목적지 시설 장애인복지관 또는 장애인지역사회재활시설 마커 서울시 사회복지시설(장애인지역사회재활시설) 목록 복지관 이동 시나리오가 실제 공공데이터 기반 목적지임을 보여준다.
대체 지원시설 교통약자 이동지원센터 또는 관련 연락처 카드 전국교통약자이동지원센터정보표준데이터의 서울 항목 이동이 어려울 때 대체 이동 지원을 안내할 수 있음을 보여준다.
횡단보도 후보 A/B A는 최단 경로 횡단보도, B는 보행지원시설 정보가 있는 우회 횡단보도로 표시 서울 자치구 횡단보도 정보, 교통안전시설물 횡단보도 정보 경로 선택이 임의가 아니라 후보 비교 결과임을 보여준다.
보행지원시설 레이어 음향신호기, 보행자작동신호기, 신호등/교통안전시설 여부 서울 음향신호기 정보, 서울 보행자작동신호기 정보, 교통안전시설물 정보 왜 특정 횡단보도가 시각장애인에게 더 설명 가능한지 보여준다.
선택된 최적 이동경로 출발지 → 우회 횡단보도 B → 복지관으로 이어지는 경로 라인 사용자 GPS, 목적지 시설 좌표, 횡단보도 후보 좌표, 보행지원시설 점수 90m 더 걷는 대신 보행지원시설 정보가 있는 경로를 선택했다는 결과를 시각화한다.
YOLO 실시간 위험 이동 중 탐지된 계단, 차량, 사람, 문, 장애물 로그 온디바이스 YOLO 탐지 결과 선택된 경로를 따라가면서도 현장 장애물을 계속 감지한다는 점을 보여준다.

YOLO와 공공데이터의 역할 분리

구분 맡는 역할 예시 대시보드 기록
공공데이터 출발 전 또는 횡단 전, 어떤 횡단보도를 선택할지 판단한다. “최단 경로보다 90m 더 이동하지만, 보행지원시설 정보가 있는 횡단보도로 안내합니다.” 시설 마커, 횡단보도 후보 A/B, 보행지원시설 점수, 우회 거리, 선택된 경로 라인, 데이터 출처
YOLO 객체 탐지 실제 이동 중 눈앞에 나타나는 즉시 위험을 판단한다. “11시 방향 사람입니다.”, “전방 2m 계단입니다.”, “오른쪽 가까이에 차량입니다.” 탐지 객체, 방향, 거리, 위험도, TTS 문장, 진동 여부
통합 판단 공공데이터로 선택한 경로를 따라가면서, YOLO가 현장 상황을 계속 보정한다. 횡단보도는 안전한 후보로 골랐지만, 현장에서 차량이나 사람이 가까우면 즉시 경고한다. 경로 선택 근거 + 실시간 탐지 로그를 같은 세션에 저장

경로 비교 예시

항목 최단 경로: 횡단보도 A 우회 경로: 횡단보도 B 판단
총 이동거리 620m 710m B가 90m 더 길다.
횡단보도 정보 횡단보도 위치는 확인됨 횡단보도 위치와 상세 시설 정보 확인 B가 설명 가능한 정보가 많다.
신호등 정보 정보 없음 또는 확인 부족 신호등 또는 교통안전시설 정보 있음 B에 가산점 부여
음향신호기 정보 없음 음향신호기 정보 있음 시각장애 보행 보조 관점에서 B 우선
보행자작동신호기 정보 없음 정보 있음 또는 후보 데이터 매칭 가능 횡단 전 행동 안내 가능
최종 선택 선택하지 않음 선택 90m 우회하더라도 보행지원시설 근거가 있는 B 경로를 선택한다.
핵심 안내 문장: “최단 경로보다 90m 더 이동하지만, 보행지원시설 정보가 있는 횡단보도로 안내합니다. 이동 중 전방 장애물은 카메라로 계속 확인합니다.”

사용 데이터와 역할

역할 데이터 시나리오에서 쓰는 방식
목적지 설정 서울시 사회복지시설(장애인지역사회재활시설) 목록 동작구 주변 복지관/장애인센터 후보를 목적지로 잡고 대시보드 지도에 시설 마커로 표시한다.
횡단보도 후보 추출 서울특별시 자치구 횡단보도 정보 출발지와 목적지 사이에 있는 횡단보도 후보 A/B를 찾는다.
신호등/교통안전시설 확인 서울시 교통안전시설물 횡단보도 정보 횡단보도 주변 교통안전시설 정보를 확인해 보행지원시설 점수에 반영한다.
시각장애 특화 가산점 서울시 음향신호기 관련 정보 음향신호기가 있는 횡단보도는 시각장애 사용자에게 더 설명 가능한 경로로 본다.
횡단 전 행동 안내 서울시 보행자작동신호기 관련 정보 보행자 버튼 신호기 정보가 있으면 “버튼 신호기 확인” 같은 안내 문장을 붙인다.
대체 이동 안내 전국교통약자이동지원센터정보표준데이터 횡단이 어렵거나 사용자가 이동을 포기할 경우, 서울 항목을 필터링해 가까운 이동지원센터 정보를 안내하고 지도/카드에 표시한다.

YOLO 현장 위험 즉시 경고 경로 점수와 별개로, 이동 중 계단·차량·사람·문·장애물이 가까우면 TTS/진동으로 바로 안내한다.
스마트횡단보도 +3점 확정 데이터 확보 시 가산점으로 추가한다. 현재 초안에서는 신호등/음향신호기/보행자작동신호기 정보로 대체한다.
