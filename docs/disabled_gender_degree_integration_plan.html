장애정도별 성별 등록장애인 데이터 반영 계획

장애인등록 장애정도별 성별 장애인수(202601~202604) CSV 4개를 VoiceGuide의 대시보드/심사자료/지역 안전 맥락에 반영하기 위한 전처리와 UI 적용 계획입니다.

CSV 4개 2026.01~2026.04 시도·시군구 장애정도 성별

1. 이 데이터의 역할

기존에 반영한 장애유형별 데이터는 “시각장애 등록 현황”을 보여주는 데 적합합니다. 이번 성별 데이터는 특정 장애유형이 아니라 전체 등록장애인의 성별·장애정도 분포를 다루므로, 앱 사용자를 직접 추정하는 데이터가 아니라 지역 복지 수요와 접근성 배경을 설명하는 보조 지표로 쓰는 것이 안전합니다.

구분 기존 장애유형별 데이터 이번 장애정도별 성별 데이터
핵심 질문 시각장애인이 어느 지역에 얼마나 있는가? 전체 등록장애인의 성별·중증도 분포는 어떤가?
대시보드 사용 현재 위치 도시의 시각장애 등록 인원 표시 현재 위치 도시의 남/여, 심한/심하지 않은 장애 비중 보조 표시
심사자료 사용 VoiceGuide의 직접 대상자 규모 근거 장애인 이동안전 서비스의 사회적 필요성 보강 근거

3. 전처리 계획

1. CSV 통합

4개 월별 CSV를 하나의 표준 CSV로 합칩니다.

2. 인코딩 정리

원본은 CP949로 읽고 프로젝트 산출물은 UTF-8로 저장합니다.

3. 지역 키 생성

sido, sigungu, region_key를 만들어 기존 지역 매칭과 연결합니다.

4. 최신월 집계

지역별 남/여, 심한/심하지 않은 장애 수와 비율을 생성합니다.

5. API 산출물

disabled_gender_degree_trend.json 2026.01~2026.04 월별 변화 심사자료/추세 차트

4. API 반영 계획

기존 /disabled-population/nearby는 현재 위치 주변 사고다발구역을 기준으로 행정구역을 찾습니다. 같은 매칭 방식을 재사용해 성별·장애정도 데이터도 현재 도시 기준으로 조회하도록 붙입니다.

API 반환 내용 대시보드 사용
GET /disabled-gender-degree/summary 최신월 전국 남/여, 심한/심하지 않은 장애 요약 전국 기준 보조 카드
GET /disabled-gender-degree/regions?limit=20 시군구별 등록장애인 성별·장애정도 집계 상위 지역 목록, 내부 검증
GET /disabled-gender-degree/nearby?lat=&lng= 현재 GPS와 가장 가까운 사고다발구역의 행정구 기준 성별·장애정도 분포 현재 위치 도시의 보조 통계

5. 대시보드 UI 적용안

현재 좌측 패널에는 이미 “시각장애 등록 현황”이 있으므로, 별도 큰 카드로 추가하면 실시간 탐지 내역을 다시 밀어낼 수 있습니다. 따라서 이번 데이터는 기존 카드 안에 접히는 보조 줄 또는 작은 토글 탭으로 넣는 것이 가장 안전합니다.

6. 실제 구현 순서

  1. tools/preprocess_disabled_gender_degree.py 생성
  2. 원본 CSV 4개를 읽어 datasets/disabled_gender_degree/에 UTF-8 산출물 저장
  3. src/api/routes.py에 summary, regions, nearby API 추가
  4. templates/dashboard.html의 기존 시각장애 카드에 작은 성별·장애정도 보조 영역 추가
  5. tests/test_api.py에 최신월 총합, 성별 합계, GPS 지역 매칭 테스트 추가
  6. 로컬 테스트 통과 후 커밋/푸시, Cloud Run 재배포

예상 테스트

python -m pytest tests/test_api.py -q
python tools/preprocess_disabled_gender_degree.py
gcloud run deploy voiceguide --source . --region asia-northeast3 --allow-unauthenticated

7. 주의할 점

  • 이 데이터는 전체 등록장애인 기준이며, 시각장애인 성별 분포가 아닙니다.
  • 사용자의 성별, 장애정도, 장애 여부를 추정하거나 저장하는 용도로 쓰면 안 됩니다.
  • 대시보드에서는 “현재 도시의 공공 통계”로만 표시하고, 개인 맞춤 판단처럼 보이는 문구는 피합니다.
  • 실시간 탐지 UI를 밀어내지 않도록 기존 카드 내부의 접힘 영역이나 작은 보조 지표로만 반영합니다.

최종 권장안

이번 CSV는 “시각장애인 수”를 대체하지 않고, 현재 위치 도시의 전체 등록장애인 성별·장애정도 분포를 보조로 보여주는 방식이 가장 적합합니다. 즉, VoiceGuide의 핵심 화면에서는 시각장애 등록 현황을 메인으로 유지하고, 이번 데이터는 지역 복지 수요/사회적 필요성/심사자료 보강에 활용하는 구조가 좋습니다.
